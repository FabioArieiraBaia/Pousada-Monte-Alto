# Pousada Monte Alto (Arraial do Cabo - RJ)

Sistema web completo para a **Pousada Monte Alto** em Arraial do Cabo - RJ, composto por **Frontend em React** (Mobile-First, i18n em 3 idiomas) e **Backend REST API em PHP com SQLite**.

## 🚀 Funcionalidades

- **Multi-idioma:** Português (PT-BR), Inglês (EN-US) e Espanhol (ES-ES).
- **Acomodações:** Gestão de Suítes e Lofts familiares com fotos, tours em vídeo no YouTube, comodidades e política Pet Friendly 🐾.
- **Reservas:** Calculadora de diárias em tempo real e integração direta com WhatsApp para confirmação em 1-clique.
- **Painel Administrativo CMS:** Dashboard com métricas, gestão de quartos, calendário de reservas, livro caixa financeiro, blog e configurações da pousada.
- **Módulo Financeiro:** Fluxo de caixa com gráficos mensais e categorização de despesas/receitas.
- **Blog:** Publicação de matérias turísticas com fotos e vídeos do YouTube.

## 🛠️ Stack Tecnológica

- **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons, React Router DOM, i18next.
- **Backend:** PHP 8+, REST API, SQLite (PDO), Autenticação Bearer Token.
